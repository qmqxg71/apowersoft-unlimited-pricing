Unlimited 是年付订阅，不是买断，停止续费之后包里的工具就不能再用。这一点跟单买终身授权是两回事，先想清楚自己接不接受。

1. **可激活几台设备。** 官方单品按设备数分档卖，商业版从 1 台起，按 2-5 台、6-10 台这样往上加价。全家桶能用几台，商品页一般会注明，没写就按一台准备，别指望装办公室五台电脑。

3. **续费价是多少。** 订阅制常见的做法是首年给优惠、续费回原价。页面只显示一个价格时，问清楚第二年扣多少，很多人的心理落差都出在这里。
